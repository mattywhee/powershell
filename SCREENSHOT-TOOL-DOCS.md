# HTML Report Screenshot Tool Documentation

## Overview

The HTML Report Screenshot Tool is a Node.js application that uses Playwright to automate the viewing and capturing of screenshots from HTML compliance reports generated by PowerShell scripts.

## Purpose

This tool helps:
- **Visualize Report Output** - Convert HTML reports into shareable PNG screenshots
- **Support Iterative Development** - Quickly view report changes during UI improvements
- **Document Example Reports** - Create visual documentation for stakeholders
- **Quality Assurance** - Verify report rendering across different scenarios

## Requirements

- Node.js (v14 or higher)
- npm (Node Package Manager)
- Chromium browser (uses system browser if available)

## Installation

1. Install dependencies:
```bash
npm install
```

This will install Playwright and its dependencies.

## Usage

### Basic Commands

```bash
# Generate a sample report and capture screenshot
node screenshot-report.js --test

# Capture screenshot of a specific HTML file
node screenshot-report.js --input report.html

# Process all HTML files in a directory
node screenshot-report.js --input ./reports

# Specify custom output directory
node screenshot-report.js --input ./reports --output ./my-screenshots

# Show help
node screenshot-report.js --help
```

### Using npm Scripts

The project includes convenient npm scripts:

```bash
# Generate test report and screenshot
npm run screenshot -- --test

# Process reports with custom paths
npm run screenshot -- --input ./my-reports --output ./output
```

## Command-Line Options

| Option | Description | Default |
|--------|-------------|---------|
| `--input <path>` | Path to HTML file or directory to process | `./reports` |
| `--output <path>` | Output directory for screenshots | `./screenshots` |
| `--test` | Generate a sample HTML report for testing | N/A |
| `--help`, `-h` | Display help message | N/A |

## Examples

### Example 1: Test the Tool

Generate a sample report and capture its screenshot:

```bash
node screenshot-report.js --test
```

Output:
- Creates `./reports/sample-report-<timestamp>.html`
- Creates `./screenshots/sample-report-<timestamp>-<timestamp>.png`

### Example 2: Single File Processing

Capture a screenshot of a specific report:

```bash
node screenshot-report.js --input C:/temp/report.html --output C:/screenshots
```

### Example 3: Batch Processing

Process all HTML reports in a directory:

```bash
node screenshot-report.js --input ./reports --output ./screenshots
```

This will:
1. Find all `.html` and `.htm` files in the `./reports` directory
2. Generate a full-page screenshot for each file
3. Save screenshots to `./screenshots` with timestamped filenames

### Example 4: Integration with PowerShell Scripts

After running the `lock-inactive-accounts.ps1` script that generates HTML email content, you can save that content to a file and capture a screenshot:

```powershell
# In your PowerShell script, save the HTML to a file
$emailContent | Out-File -FilePath "C:\temp\reports\account-lock-report.html" -Encoding UTF8

# Then use Node.js to capture the screenshot
node screenshot-report.js --input C:\temp\reports\account-lock-report.html
```

## Output

### Screenshot Format

- **Format**: PNG (Portable Network Graphics)
- **Type**: Full-page screenshot (captures entire scrollable content)
- **Viewport**: 1280x720 (can be modified in the script)
- **Naming**: `<original-filename>-<timestamp>.png`

## Architecture

### Technology Stack

- **Playwright**: Browser automation framework for capturing screenshots
- **Node.js**: JavaScript runtime environment
- **Chromium**: Browser engine (uses system installation when available)

### Key Features

1. **System Browser Detection**: Automatically uses system Chromium if available, falling back to Playwright's bundled browser
2. **Full-Page Capture**: Screenshots include all content, not just the visible viewport
3. **Batch Processing**: Efficiently processes multiple files in a single run
4. **Error Handling**: Graceful error handling with informative messages
5. **Flexible Configuration**: Command-line arguments for customization

## Troubleshooting

### Issue: "No HTML files found"

**Solution**: Verify the input path exists and contains `.html` or `.htm` files.

```bash
# Check if files exist
ls ./reports/*.html

# Use absolute path
node screenshot-report.js --input /full/path/to/reports
```

### Issue: Browser download fails

**Solution**: The script is configured to use the system Chromium browser. Ensure Chromium is installed:

```bash
# Check if Chromium is installed
which chromium || which chromium-browser
```

### Issue: Permission denied when creating directories

**Solution**: Ensure you have write permissions for the output directory:

```bash
# Create the directory manually
mkdir -p ./screenshots
chmod 755 ./screenshots
```
